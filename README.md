# IronLog — 30 Day Strength Challenge (Android)

## Get the APK via GitHub (no Android Studio needed)
1. Create a new repo on github.com (private is fine) and upload this whole folder.
2. Open the repo's **Actions** tab -> "Build IronLog APK" runs automatically (~3-5 min).
3. Open the finished run -> download **IronLog-apk** -> unzip -> `app-debug.apk`.
4. Copy to your phone, tap it, allow "Install unknown apps" when prompted.

## Or with Android Studio
Open this folder -> let it sync -> Build > Build App Bundle(s)/APK(s) > Build APK(s).

Your data is stored on the phone only. Uninstalling the app clears it.
